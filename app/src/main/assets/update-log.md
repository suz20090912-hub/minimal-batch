## v1.2 — 2026-11-25

**主题**：结构与安全感。只改"用得顺手"的部分，不加任何新的处理能力。

### 修掉的问题

| 反馈 | 根因 | 改法 |
|---|---|---|
| 手滑一下手势返回就退出，回来得重新选几十张图 | 根页面的返回直接 `finish()`，选图只活在内存里 | ① 有未完成工作时，返回先弹确认框（取消/退出）；② 正在处理时返回被挡住，只提示 `正在处理 N/M`；③ 选图列表落盘 + `takePersistableUriPermission` 长期授权，冷启动自动恢复上次的选图，已被删掉的图静默剔除 |
| PNG 透明底转 JPEG 变成黑块 | JPEG 不支持 alpha 通道，透明区被填成黑 | 编码前先合到白底（`flattenOnWhite`）；预览也走同一条路，所见即所得 |
| 处理完只知道目录名，得退出 App 自己翻 | v1.1 只有一个结果卡 + 文字路径 | 成品页：按场景分组的网格，点开全屏，右上角可交给系统看图应用 |

### 新增

- **底部三个页面**：转换 / 成品 / 设置。切页不影响处理，进度条在转换页继续走。
- **成品按场景分文件夹**：`Pictures/极简批处理/微信发送`、`/存档原图`、`/社交方图`。不依赖数据库，扫目录就能分类；系统相册里也会多出这三个相册。v1.0 留下的平铺老图归到「未分类（旧版）」。
- **输出位置可改**：默认还是 `Pictures/<文件夹名>`，文件夹名可改；也可以用系统文件夹选择器选任意目录（SAF，长期授权）。换位置只影响以后的处理，老图不动。
- **设置页**：默认场景、输出位置、清空已选、关于（版本 / 协议 / 权限声明 / 项目主页）、**离线更新日志**。
- **更新日志内置**：`assets/update-log.md`，和仓库里的 CHANGELOG 同源，装机后不联网也能翻版本记录。

### 已知不足

- 选到自定义文件夹后，系统相册不一定索引这些图，请在 App 的「成品」页看。
- 成品页只列当前输出目录；换过位置后，旧目录里的图不会出现在列表里（文件本身还在）。
- 还没有联网检查更新 —— 排到 v1.3，且只在你手动点击时才联网。

## v1.1 — 2026-11-25

**主题**：第一批真机反馈，只修功能，不动视觉。

### 修掉的问题

| 反馈 | 根因 | 改法 |
|---|---|---|
| 标题「极简批处理」和手机左上角的时间重叠 | `targetSdk 35` 起系统强制 edge-to-edge（内容画到屏幕最顶上），v1.0 布局没吃安全区 inset | 整页套 `safeDrawingPadding()`，标题、场景条、按钮、列表全部落在状态栏和手势条之内 |
| 处理完只知道目录名，得退出 App 自己去找 | v1.0 结果卡只显示文字路径 | 结果卡加「看这批图」：双列成品网格 → 点图全屏 → 右上角「相册」把第一张交给系统看图应用 |

### 新增

- **选图即时预览**：选完图或切换场景，按当前预设**真跑一遍**（解码 → 缩放/裁方 → JPEG 编码），结果只留在内存做缩略图、**不写盘**，生成「原图 → 处理后」对照卡片，附目标尺寸和**预计体积**（如 `1920×1440 · 预计 412KB`）。单张约 115ms，3 路并行，一次最多预跑 20 张。
- 原图列表每行也补上「预计体积」，和预览卡片对得上。
- `applyTargetSize()` 从正式处理里抽出来，预览和正式处理共用同一套尺寸计算，避免「预览说 1920、实际出来 1800」。

### 已知不足

- 预览上限 20 张，超出的部分只有尺寸估算，没有缩略图。
- 成品相册只显示当前这一批（v1 没有历史记录）。
- 视觉仍是最朴素的，美化排在后面。

## v1.0 — 2026-11-24

首个可用版本。

- 四功能：压缩 / 改尺寸 / HEIC→JPG / 重命名
- 三场景预设：微信发送 1920/q82、存档原图 原尺寸/q90、社交方图 1080 中心裁切/q85
- 3 路并行管线，解码阶段就按目标尺寸采样（12 张 50MP：1.59s，峰值 311MB）
- 输出写 `Pictures/极简批处理`，走 MediaStore，不需要存储权限
- 「撤销这批」按 `outUri` 删除刚写入的文件，原图永远只读
- 无网络权限、无账号、无广告

### 这一版已知的问题（v1.1 / v1.2 已修）

- 顶部标题被状态栏压住（v1.1 修）
- 处理完成后没有成品浏览入口，只能记目录名（v1.1 加入口，v1.2 做成成品页）
- 误触手势返回会丢掉已选图（v1.2 加确认框 + 会话恢复）
