## 一、这是什么

一个完全离线的 Android 批量图片处理工具，给做内容、发图文的人用：选一批图 → 选场景 → 一键压到合适尺寸/体积 → 直接写进相机的相册文件夹。

三条底线：不登录、不联网处理、图片不上传。完全开源免费，不设赞助渠道，也没有付费版。

技术底子：Kotlin + Jetpack Compose，minSdk 29 / target 35，包名 `dev.localbench.batch`，正式签名密钥在 `release-key/minimal-batch.jks`（已交付，务必自行备份，丢了就没法覆盖升级）。

## 三、已经定下来的设计（别再来回改）

- **返回层级**：一层一层退——全屏图 → 更新中心/公告/更新日志 → 非转换页回转换页 → 根页才问退不退。选择模式、移出模式这类临时态，返回只退出该模式。
- **成品组织**：场景即子文件夹，零数据库；`Pictures/极简批处理/<场景名>`，或用户自选 SAF 目录。
- **输出位置**：默认 Pictures 下可改名，也可选别的文件夹；换位置只影响以后，老图不动。
- **删除入口**：只放两处——成品页长按多选删、看图页右上单张删；结果卡不再有删除按钮。
- **更新检查**：仅手动触发、确认框先行、镜像站优先、内置 6 条列表 + 测速 + 自动/手动 + 代理；错误分类；单独条目在设置里。
- **公告编号**：`NoticeStore.ID` 改大就让人重新看到小圆点，v1.4.0 起 1 → v1.6.2 起 8。
- **节奏**：一版只加一类能力、每版真机验收、每版发 Release、每版 push 源码。

## 四、最近三版（v1.6.x）的细节

### v1.6.0：选图回到看原图

- 以前选完图会按预设真跑一遍生成“处理后的样子”，费时间也吃内存。整排预览卡连同进度条一起去掉。
- 改成 3 列原图网格，每格是缩略图 + 体积，总览一行“已选 N 张 · 共 X”。
- 点原图进看图页：左右翻页、双指缩放、右上 ⓘ 看文件名/尺寸/大小/格式/位置；**只读**，底部分享/编辑整行不出现，右上删除也不出现。
- 成品页处于选择模式时按返回，先退出选择，不再一跳回转换页。

### v1.6.1：结果记录能自己清

- 结果卡底部两个按钮：「展开每张明细」「清除记录」。清除只把这条记录从会话里拿掉，回到选图状态，一张图片都不删。
- 设置里「清空已选图片」也会顺带把记录清掉，不会再出现选了空、卡还挂着。
- 更新日志重排：正文 12 → 15 号字、行距 25、标题分三级；`**`、反引号、`---` 不再原样显示；版本表格在 App 内不渲染（窄屏会挤成一团），完整表格仍留在仓库 CHANGELOG。

### v1.6.2：不转的那张，长按移出

- 选图网格长按任意一张，进「移出」模式：长按那张默认已勾，再点几张加减，顶部「移出 / 取消」。
- 点「移出」只改这批名单，原图不动、不删、授权不动，剩余张数和总体积立刻变。
- 移出模式里按返回只退出该模式，不会把选好的全丢。
- 全移空时网格位置显示“这批已经空了，点上面的「选择图片」重新挑”。

## 六、工程与交付流程

Windows 上没有 git / JDK，所以流程固定成这样：

1. Windows 改源码与文档 → 打包 `batch-app.zip`
2. 上传 CDN 拿一个临时直链
3. 切 Linux 云主机：下载解压到 `~/ktcheck/batch-app`，补 4 处构建配置（`buildToolsVersion`、`gradle.properties` 内存与并行、`local.properties`、`keystore.properties`），`gradle assembleRelease`（JDK17 / Gradle 8.9，约 2 分 15 秒）
4. APK 上传 CDN 回传 Windows（校验字节数与 SHA-256）
5. `present_files` 交付安装包
6. GitHub 走 REST 增量推 blob/tree/commit（`push_files.ps1`），先建 tag ref → 建 Release → 上传资产（asset）→ 最后改 `version.json`
7. 每次都核对：开发工程 `batch-app/` 与仓库镜像 `minimal-batch/` 同名文件哈希一致，否则会推旧代码

踩过且要记住的坑：Gradle Kotlin DSL 里 `java.util.Properties()` 会被当成 Gradle 的 `java` 扩展（要显式 import）；`EnterTransition` 与 `ExitTransition` 不能混用；PowerShell 单引号里的 `` `r`n `` 不转义；`$变量:` 紧跟冒号要写 `${变量}`；部分源码 CRLF 部分 LF，多行替换要用 Edit 工具而不是字符串 Replace。

## 七、已知限制

- 删除没有回收站，删了就是删了。
- 选图网格只显示原图体积，看不到“处理后会多大”，要估体积得先去成品页。
- 结果记录只存在内存里，冷启动就没了（有意为之，避免下次打开还挂上一批）。
- 移出图之后原授权记录还留着，不影响使用，只是没做回收。
- 非主存储卷（SD 卡、网盘目录）的写入没法用 MediaScanner 兜底，只能靠成品页找到。
- 仓库 `screenshots/` 仍是占位，等四张实机截图。
