# 极简批处理 · Minimal Batch

手机端纯本地批量图片处理：压缩 / 改尺寸 / HEIC→JPG / 重命名

无账号、无广告、不上传云端，选图 → 预览 → 处理 → 看图，四步走完

## 为什么做这个

相册里一堆 HEIC 发不出去、微信一发就压成马赛克；网盘和修图 App 要么让你登录，要么先把你几十张照片传上云，要么为了四个功能塞进两百兆的界面。

所以做了这个：**只做四件事，只在你手机里做。**

## 它只干四件事

| 功能 | 说明 |
|---|---|
| 压缩 | 按目标长边重编码 JPEG，质量可调 |
| 改尺寸 | 长边缩到 1920 / 1080，或保持原尺寸 |
| 转格式 | HEIC / PNG / WebP → 通用 JPG |
| 重命名 | 统一前缀 + 序号，如 `旅行_001.jpg` |

## 三个场景预设

不用懂参数，选场景就行：

- **微信发送** — 长边 1920，JPEG q82，发出去不糊、不被二次压坏
- **存档原图** — 保持原尺寸，q90，只把 HEIC 换成通用 JPG
- **社交方图** — 中心裁成 1080 方图，q85，做头像和种草图

## 四步走完

1. 选图（一次可选几十张）
2. 选场景（或填一个重命名前缀）
3. 点「开始处理」，上面有实时进度
4. 处理完点「看这批图」，直接进成品网格

### 选完图先看效果，不用赌

选完图、切换场景，App 会按当前预设**真跑一遍**（解码 → 缩放/裁方 → JPEG 编码），但**只留在内存里做缩略图、不写盘**。所以每张卡片上都是真实的「原图 → 处理后」对照，外加目标尺寸和预计体积（例如 `1920×1440 · 预计 412KB`）。一次最多预跑 20 张，3 路并行，等不了就取消重选。

### 处理完直接看图，不用去翻目录

成品写进 `Pictures/极简批处理`，App 里给了**成品页**：按场景分组的网格、点开全屏、右上角「相册」可以把第一张交给系统看图应用。不用记路径、不用退出 App 去找文件夹。

跑完还有一张总账：原图多少 MB → 现在多少 MB、省了几个百分点；每张的尺寸和体积都能核对。
不满意就点 **「撤销这批」**，把刚写出去的图删干净 —— **原图永远只读，不会被覆盖。**

### 三个页面，各干一件事

| 页面 | 干什么 |
|---|---|
| **转换** | 选图、选场景、看预览、开始处理、看这批的总账和撤销 |
| **成品** | 全部处理结果，按 `微信发送 / 存档原图 / 社交方图` 分类，点开全屏 |
| **设置** | 默认场景、输出位置、清空已选、关于、离线更新日志 |

切页不影响处理：进度条留在转换页，任务在后台继续跑。

### 手滑退出不会白干

手势返回误触是手机上的高频事故。这里做了三层兜底：

1. 有未完成的工作（选了图 / 有结果）时，返回先弹「取消 / 退出」确认框；
2. 正在处理时，返回直接被挡住，只提示 `正在处理 8/12`，滑不出去；
3. 选图会落盘并申请长期读权限，下次打开自动恢复上次的选择 —— 真退出了，也不用重选几十张。
## 实测数据（vivo V2302A，Android 16，天玑 9200 级）

12 张 5000 万像素（8192×6144）原图，3 路并行：

| 方案 | 12 张总耗时 | 单张位图内存 | 进程峰值 |
|---|---|---|---|
| 整张解码再缩放 | 2.09s | 192MB | 552MB |
| **解码阶段就按 1920 采样** | **1.59s** | **10MB** | **311MB** |

结论：**耗时的大头不是解码，而是"把整张图铺成位图再缩回去"**。所以这个 App 从解码器上就按目标尺寸采样，速度更快、内存省一半以上。

更详细的测量方法和数据见 [docs/measurements.md](docs/measurements.md)。

## 从源码编译

需要 JDK 17 与 Android SDK（API 35）：

```bash
git clone https://github.com/suz20090912-hub/minimal-batch.git
cd minimal-batch
./gradlew assembleDebug
```

产物在 `app/build/outputs/apk/debug/app-debug.apk`。
用 Android Studio 打开也行：`File → Open` 选仓库根目录，等 Sync 完直接 Run。

## 设计取舍

- **不做"全能修图"**：滤镜、拼图、去水印都不做。只解决"批量把图变小、变通用"。
- **不覆盖原图**：所有输出都是新文件，写进 `Pictures/极简批处理`，撤销就是删新文件。
- **预览也不落盘**：预览用的缩略图只在内存里，选完图不会在相册里多出一堆垃圾文件。
- **不申请存储权限**：默认走 MediaStore，Android 10+ 无需权限即可写入自己的输出；只有你主动选自定义文件夹时才使用系统文件夹授权的 SAF。
- **不联网**：没有网络权限，图片不出手机。
- **没有数据库**：成品分类靠"场景子文件夹"这种物理约定，不维护索引表，所以不会出现"相册删了图、App 还记着"的问题。

## 已知限制

- 只输出 JPEG，暂不支持输出 HEIC/PNG/WebP
- 单进程 3 路并行，超大图（>50MP）批量时仍可能触发系统内存回收
- 预览一次最多 20 张（再多就靠列表里的尺寸/预计体积估算）
- 成品页只列当前输出目录；换过位置后旧目录的图不在列表里（文件还在）
- 选到自定义文件夹时，系统相册不一定索引这些图，请在 App 内查看
- 还没有联网检查更新（v1.3 单独做）
